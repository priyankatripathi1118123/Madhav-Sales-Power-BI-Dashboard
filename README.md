# 📊 Madhav Sales Performance & E-Commerce Analytics Dashboard

An interactive Business Intelligence (BI) dashboard built using Power BI to analyze retail sales, revenue trends, regional performance, and customer purchasing behaviors for Madhav Store.


## 🚀 Project Overview
This project provides deep-dive analytics into retail sales data. It helps business stakeholders track key revenue metrics, evaluate regional performance, identify top-selling product sub-categories, and monitor fulfillment trends dynamically.


## 🛠️ Technical Stack & Tools Used
* **Data Visualization & BI Tool:** Power BI Desktop (Report View, Data Pane, Format Visual Pane)
* **Dataset:** Madhav Sales Dataset (`train.csv` / Excel)
* **Core Components & Visuals:**
  * **KPI Summary Cards:** Track Total Sales (`Sum of Sales`) and Total Orders (`Count of Postal Code`) instantly.
  * **Column & Area Charts:** Detailed breakdown of revenue across Product Categories and Sub-Categories.
  * **Donut Chart:** Regional sales distribution mapping performance across multiple zones.
  * **Interactive Slicers:** Dynamic customer segment filtering (Consumer, Corporate, Home Office).
* **Design & Formatting:** Custom visual containers, optimized font scaling, clean axis title styling, and professional layout alignment.

## 📈 Key Business Insights & Features
* **Dynamic Interactivity:** Real-time cross-filtering across all charts using interactive slicers and data points.
* **Product Optimization:** Highlights high-performing categories and sub-categories to assist in inventory planning.
* **Geographic Breakdown:** Visualizes market reach and regional sales concentration.
